These patterns belong to the current job and travel with its .syncto file. Right-clicking any row in the grid or the overview adds patterns here too.
One pattern per line (or separated by |). * is any run of characters inside one name, ? is exactly one. End with / to mean folders only, with : to mean files only.
No / anywhere → it matches the item's name, at any depth: *.tmp · thumbs.db · Proxies/ (the trailing slash only means "folders only", it does not count).
A / anywhere in it → it matches the path from the top of the pair, and only there. A leading / changes nothing: Rushes/A001/ and /Rushes/A001/ are the same pattern, and neither one reaches DAY2/Rushes/A001. Use */Rushes/A001/ for that.
